Guía rápida de desarrollo - Backend

Pasos para crear el entorno virtual e instalar dependencias:

1. Crear el entorno virtual:

```bash
python3 -m venv octofit-tracker/backend/venv
```

2. Instalar las dependencias listadas en `requirements.txt`:

```bash
source octofit-tracker/backend/venv/bin/activate
pip install -r octofit-tracker/backend/requirements.txt
```

Este repositorio ignora el directorio `venv`, por lo que el entorno virtual no está versionado.

Comandos usados por el agente para esta sesión:

```bash
python3 -m venv octofit-tracker/backend/venv
octofit-tracker/backend/venv/bin/pip install -r octofit-tracker/backend/requirements.txt
```
